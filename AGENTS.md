# AI-Sales-Assistant

Это проект B2B-лидогенерации для Codex. Отвечай пользователю по-русски.

- Для продаж используй `.agents/skills/prodazhi/SKILL.md` и соответствующий навык шага.
- Рабочая папка — корень этого репозитория. Все команды запускай здесь; скрипты лежат в `scripts/`.
- `bash install.sh` проверяет Python и создаёт локальный `config.json`, сохраняя существующий.
- Конфиг, базы, выгрузки и отчёты — локальные данные: не коммить их.
- Не выводи почтовые пароли в чат. Для чтения портрета используй `python3 scripts/configuration.py --summary`.
- Демо-портрет в примере не является заданием пользователя. Уточни продукт, регион и критерии перед живым сбором.
- Проверяй факты через `verify.py`; сохраняй ссылки и даты источников. Не трактуй отсутствие данных как ноль.
- Соблюдай стоп-лист. Отправка писем не реализована: разрешены локальные файлы и IMAP-черновики по запросу пользователя.
- Перед сетевыми запросами проверь параметры и доступность источника. При блокировке покажи причину; не выдавай демо за реальные данные.

Проверка изменений: `python3 -m unittest discover -s tests -v` и `python3 scripts/report.py --demo --out out/demo`.
