# AI Sales Assistant

**ИИ-ассистент для поиска B2B-клиентов и подготовки персональных предложений.**

Помогает пройти путь от описания целевой аудитории до списка компаний и черновиков писем. Работает с открытыми реестрами ФНС и публичной информацией о компаниях.

Проект развивает **Сергей Марина** — внедрение ИИ в бизнес-процессы, маркетинг и продажи.

## Возможности

- **Портрет клиента:** определение критериев поиска под ваш продукт.
- **Поиск компаний:** сбор потенциальных клиентов из открытых реестров.
- **Отбор:** исключение компаний, которые не подходят под заданные условия.
- **Обогащение:** поиск публичных контактов и дополнительной информации.
- **Анализ сайтов:** поиск сигналов, которые помогут подготовить предложение.
- **Персональные письма:** создание обращений с проверкой фактов.
- **Черновики:** сохранение писем локально или в папке черновиков почты.
- **Отчёты:** HTML-отчёты для просмотра результатов.

Письма остаются черновиками. Решение об отправке принимает пользователь.

## Быстрый старт

### 1. Установите проект

Нужен Python 3.9 или новее.

~~~bash
git clone https://github.com/SergeyMarina/AI-Sales-Assistant.git
cd AI-Sales-Assistant
bash install.sh
~~~

На Windows используйте WSL или Git Bash с Python в PATH.

Встроенный парсер читает XLSX без дополнительных библиотек. При необходимости можно установить зависимости:

~~~bash
python3 -m pip install -r requirements.txt
~~~

### 2. Откройте проект в Codex

В приложении Codex откройте папку `AI-Sales-Assistant` и создайте чат.

При работе через CLI запустите `codex` из папки проекта.

### 3. Опишите свой продукт и клиентов

Напишите в чате:

~~~text
$prodazhi портрет
Я предлагаю [продукт или услугу].
Ищу [тип компаний] в [регионе].
~~~

Например:

~~~text
$prodazhi портрет
Я предлагаю доставку корпоративных обедов.
Ищу офисы и производственные компании в Ростове-на-Дону.
~~~

Перед сбором данных настройте свою нишу. Перевозки и Татарстан в исходных настройках используются как демонстрационный пример.

## Рабочий сценарий

| Шаг | Сообщение в Codex |
| --- | --- |
| Определить целевую аудиторию | `$prodazhi портрет` |
| Собрать список компаний | `$prodazhi список` |
| Отобрать подходящие компании | `$prodazhi отсев` |
| Дополнить сведения и контакты | `$prodazhi обогащение` |
| Найти основания для предложения | `$prodazhi сигналы` |
| Подготовить персональные письма | `$prodazhi письмо` |
| Сохранить черновики | `$prodazhi черновики` |

Можно описывать задачи обычными словами. Эти команды вводятся в чате Codex, а не в терминале.

Подробная инструкция: [GUIDE.md](GUIDE.md).

## Демо без подключения к интернету

~~~bash
python3 -m unittest discover -s tests -v
python3 scripts/report.py --demo --out out/demo
~~~

В папке `out/demo/` появятся пять HTML-отчётов на вымышленных данных. Демо позволяет посмотреть формат результатов без живого сбора.

## Настройки и данные

Установка создаёт локальный `config.json` и сохраняет его при повторном запуске.

- `config.json` — параметры поиска и подключения.
- `data/` — рабочие данные.
- `out/` — отчёты и выгрузки.

Эти файлы и папки исключены из Git. Не добавляйте пароли и почтовые доступы в репозиторий.

Скрипты читают конфигурацию из корня проекта. Переменная `AIOP_CONFIG` позволяет указать другой путь к конфигу.

Для работы нужен доступ к Codex. Отдельный API-ключ модели в скриптах не требуется.

## Работа с почтой

Перед созданием черновиков письма проходят проверку фактов и стоп-листа.

- `drafts.py --dry-run` сохраняет локальные файлы EML.
- `drafts.py --append` добавляет письма в IMAP-черновики.

Для подключения через IMAP нужен пароль приложения. Можно работать только с локальными файлами, без подключения почты.

## Источники данных

Живой сбор требует подключения к интернету и разрешений среды Codex.

Доступность сервисов ФНС может различаться. Если источник недоступен, можно использовать ранее сохранённую XLSX-выгрузку.
