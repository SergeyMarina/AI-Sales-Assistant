# AI-Sales-Assistant для Codex

B2B-лидогенерация по открытым реестрам ФНС: портрет клиента → список компаний → отсев → обогащение → диагностика сайтов → письма → черновики.

Адаптация [Comandosai/ai-otdel-prodazh-ru](https://github.com/Comandosai/ai-otdel-prodazh-ru) для Codex. Python-скрипты и проверка фактов сохранены. Команды Claude Code заменены навыками в `.agents/skills/` и инструкциями `AGENTS.md` по [документации Codex](https://developers.openai.com/codex/skills/).

## Быстрый старт

```bash
git clone https://github.com/SergeyMarina/AI-Sales-Assistant.git
cd AI-Sales-Assistant
bash install.sh
```

Нужен Python 3.9+. На Windows используйте WSL или Git Bash с Python в PATH. `openpyxl` необязателен: встроенный парсер читает XLSX без дополнительных библиотек. По желанию: `python3 -m pip install -r requirements.txt`.

В приложении Codex откройте **папку AI-Sales-Assistant** как проект и создайте чат. В CLI запустите `codex` из этой папки. Напишите:

```text
$prodazhi портрет
Я предлагаю [продукт]. Ищу [тип компаний] в [регионе].
```

Далее: `$prodazhi список`, `$prodazhi отсев`, `$prodazhi обогащение`, `$prodazhi сигналы`, `$prodazhi письмо`, `$prodazhi черновики`. Можно писать обычными словами. Это сообщения агенту, а не команды терминала.

Установка создаёт один локальный `config.json` и сохраняет его при повторном запуске. Она не требует Claude Code, не копирует файлы в домашнюю папку и не меняет настройки Codex. Перевозки и Татарстан — демо, перед сбором настройте свою нишу. API-ключ модели в скриптах не требуется; нужен доступ к самому Codex.

## Проверка без сети

```bash
python3 -m unittest discover -s tests -v
python3 scripts/report.py --demo --out out/demo
```

В `out/demo/` появятся пять HTML-отчётов на вымышленных данных. Подробный рабочий порядок: [GUIDE.md](GUIDE.md).

## Данные и почта

`config.json`, базы `data/`, отчёты `out/` и выгрузки исключены из Git. Не коммитьте почтовые доступы. Скрипты читают конфиг из корня проекта; `AIOP_CONFIG` задаёт явный альтернативный путь. Дата среза МСП по умолчанию вычисляется автоматически.

Письма проходят проверку фактов и стоп-листа. `drafts.py --dry-run` создаёт локальные EML, `--append` кладёт их в IMAP-черновики. Автоматической отправки нет. Для IMAP нужен пароль приложения; можно пользоваться локальными файлами без подключения почты.

Живой сбор требует доступа к интернету и разрешений среды Codex. Доступность сервисов ФНС зависит от сервиса, IP и текущих ограничений. При недоступности используйте ранее сохранённую XLSX-выгрузку; демо не заменяет живые данные.

## Структура

- `.agents/skills/` — общий навык `prodazhi` и семь навыков шагов.
- `AGENTS.md` — инструкции для Codex.
- `scripts/` — источники ФНС, обогащение, проверка, письма, черновики и отчёты.
- `assets/` — оформление отчётов.
- `config.example.json` — пример профиля с пустыми доступами.
- `tests/` — проверки установки и локального конфига.
